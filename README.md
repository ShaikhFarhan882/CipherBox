# CipherBox

CipherBox is an Android application that allows users to convert plain text into various cipher formats using popular encryption and encoding algorithms. Built with Kotlin using MVVM architecture, the app ensures secure and efficient processing with smooth navigation.

## Features

- Convert plain text to multiple cipher formats:
  - Base64 encoding
  - MD5 hash
  - SHA-1 hash
  - SHA-256 hash
  - SHA-512 hash
- Uses Kotlin Coroutines for fast and efficient background processing
- Clean and maintainable MVVM architecture
- Smooth navigation flow with Android Navigation Component
- Simple, user-friendly interface for easy text encryption


## Usage

- Enter the plain text you want to encrypt.
- Choose your desired cipher method.
- View the encrypted output instantly.
- Share or copy the result as needed.
